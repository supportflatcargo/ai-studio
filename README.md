# Palliq 🪵🤖

**Palliq** is an open-source, AI-powered computer vision application designed to automate wooden pallet quality assessment and counting directly from smartphone and mobile photographs.

## 🚀 The Problem & The Gap

Traditional pallet sorting and inspection in lumber yards, recycling facilities, and logistics hubs are manual, slow, and prone to human error. This creates heavy bottlenecks in supply chain reconditioning and timber logistics. 

Palliq bridges this gap by leveraging advanced multimodal AI to deliver instant, automated on-site grading (identifying broken blocks, missing boards, EPAL compliance) and precise counting to streamline circular supply chains.

---

## ✨ Key Features

* **Instant AI Counting:** Detect and count stacked wooden pallets accurately from a single image capture.
* **Quality & Defect Grading:** Assess pallet condition (detecting structural damage, missing elements, or wear) to ensure compliance with standards (e.g., EPAL/EUR).
* **Mobile-First Workflow:** Optimized for quick on-site field capture using standard smartphone cameras.
* **Multimodal Intelligence:** Powered by cutting-edge vision APIs to process industrial use-case imagery seamlessly.

---

## 🛠️ Tech Stack

* **Frontend & Core:** React, TypeScript, Vite, Tailwind CSS / UI components
* **AI & Vision:** Google Gemini API / Advanced Multimodal Models
* **Runtime:** Node.js
